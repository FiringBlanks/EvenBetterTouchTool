# EvenBetterTouchTool 2.7.1 — Visible finger counts

The Fingers column now uses compact **3** and **4** buttons instead of hand icons. Colored status dots, disabled-row styling, hover/accessibility descriptions, and Save/Reset behavior are retained. Existing mappings and settings are preserved.

The app is built and checked with the existing 241-check suite. This is a visual-label change; no gesture recognition or action behavior changes. Local ad-hoc builds may need fresh Accessibility and Input Monitoring approval after updating.
